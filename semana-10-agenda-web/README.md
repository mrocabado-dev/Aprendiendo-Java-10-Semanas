# Agenda Web Completa

Aplicacion web desarrollada con Spring Boot y Vaadin.

## Funcionalidades

- Gestion de contactos
- Gestion de eventos
- Persistencia JSON
- Binder
- Grid
- DatePicker
- Notification
- Arquitectura por capas
- Tests unitarios

## Tecnologias

- Java 21
- Maven
- Spring Boot
- Vaadin
- Gson
- JUnit 5

## Ejecutar

```bash
mvn spring-boot:run
```

## Ejecutar pruebas

```bash
mvn test
```
